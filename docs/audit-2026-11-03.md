## What is working

- **Tokens.** 594 CSS tokens from 646 Figma variables, every one with a description, aliases resolved, both themes in one file, `data-theme` or the system preference. The lint names the token to use, so an agent fixes a miss in one pass. The token audit earlier today found every token either in use or holding a role no other token covers.
- **One source per fact.** Values live in Figma, behaviour in the repo, and the component map connects them property by property. A drift check reports any difference variable by variable.
- **Components.** Controlled and uncontrolled props follow one pattern (`value` / `defaultValue` / `onValueChange`, `open` / `onOpenChange`, `checked` / `onCheckedChange`). Shared internals (tabs, overlay, message, menu items, date field) keep similar components from drifting apart. React Aria handles behaviour only, and all styling is Bland's.
- **States.** Focus is `:focus-visible` everywhere, disabled uses tokens, never opacity, and motion has a reduced-motion fallback in every component.
- **Figma hygiene.** Every text layer uses a text style, every shadow an effect style, private parts start with `_`, and the doc pages are built from the same variables.

### Differences that are intentional (not issues)

- `Fade/menu-clear`, `calendar-clear`, `text-input-clear` and `text-input-hover-clear` are bound nowhere in Figma: code draws its fade as a mask, so these Figma-only drawing aids aren't needed (Godwin, 2026-11-03).
- Default sizes that differ from Figma's default variant (Button and Avatar md, Calendar md): the touch target and the common case, recorded in the component map.
- Code-only additions recorded in the component map: Slider `snap`, Progress-wizard `fill`, Breadcrumb wrapping, Dropdown chips wrapping, Logo `children`.
- `👀 Focused` booleans in Figma become `:focus-visible` in code.
- Components that fill their container in code where Figma has a frame width.

## Recommended order

1. **Accessibility first** (issues 1 to 3): they reach end users of every project. Issues 2 and 3 are code-only and quick; issue 1 is a token decision.
2. **Figma hygiene** (4, 8, 9, 10, 12): one approval list, one script per set, then a drift check.
3. **Governance** (14, 15, 16, 17): publish the library, host the docs, write the deprecation rule, start the projects list.
4. **Coverage** (5, 6, 7): only as client projects ask.
5. **Notes** (11, 13): small, any time.

## Keeping it from coming back

- Run this audit's two Figma scans (variable and style census, raw values per set) after each round of Figma work; they are read-only and take one call each.
- The drift check after every Figma session, as now.
